How many decibels above the estimated noise floor a signal must be to count as a spike. Lower = more sensitive. Typical values: 3–8 dB. Start at 4 dB.
0.85 0.40
Two smoothing factors for the adaptive noise floor. "Alpha rise" controls how quickly the baseline increases when levels go up (larger values = slower). "Alpha decay" controls how quickly the baseline drops when levels fall (smaller values = faster response). Use faster decay for more dynamic environments; use slower rise to avoid reacting to short bursts.
0.5
How often the UI requests the current averaged levels and spike state (in seconds). Shorter intervals give faster feedback but increase CPU and UI updates. 0.2–0.5s is a common tradeoff.

Quick tips

  • Find device index: If you're not sure which device number to use, run a small Python snippet that prints sounddevice.query_devices() or try incrementing device index until you get audio.
  • Channel numbering: Channels are zero-based. To monitor physical channels 7 & 8 enter "6,7".
  • Sensitivity tuning: If you see too many false positives, raise the Threshold. If spikes are missed, lower the Threshold or make Alpha decay smaller (faster).
